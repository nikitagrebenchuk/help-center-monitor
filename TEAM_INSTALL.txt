INSTALL HELP CENTER MONITOR
===========================

Do this once. You do not need Terminal, Python, or source code.

Before you start
----------------
- macOS 13 or newer
- The Slack token sent separately through the company password manager or
  approved secret-sharing tool

Never put the token in email or an ordinary Slack message.

Install
-------
1. Drag Help Center Monitor onto Applications. Choose Replace if macOS says an
   older copy already exists.
2. Open Help Center Monitor from Applications.
3. If macOS says Help Center Monitor was not opened, click Done. Do not click
   Move to Trash.
4. Return to this disk image and open
   "2 - After Warning - Open Privacy & Security".
5. In the Security section, click Open Anyway beside Help Center Monitor.
   Authenticate with Touch ID or your Mac password, then click Open.
   If the app opened normally in step 2, skip steps 3 through 5.
6. Eject this disk image.
7. Click Allow when macOS asks about notifications.
8. Paste the separately supplied token into the secure setup box with Command+V,
   then click Save. If needed, click Set Up Slack Access first.
9. Make sure the Monitoring switch is green and on. Choose Immediate for every
   new customer-message event, or Pylon 2 min for only Pylon's verified
   two-minute first/next-response SLA breaches.

With Pylon 2 min selected, use Verify Pylon 2-Minute Feed to run a read-only
source check and send a labeled two-minute test alert without posting to Slack.
The app does not inspect customer channels, #help-center, or Pylon assignees.

The Privacy & Security approval is required once for this internal unsigned
build. A newly rebuilt version may require the same approval again.

Confirm it works
----------------
The panel should show Monitoring, Secured credentials, Enabled alerts, a recent
Last checked time, and a green automatic-login status.

If automatic start needs approval, click the menu-bar bell, choose Allow
Automatic Start, and enable Help Center Monitor in System Settings > General >
Login Items. Return to the app and confirm the bottom line is green.

Turn up the Mac's output volume and click Send Test Alert. Expect:
- a notification banner
- the Glass alert sound
- the spoken words: "New ticket in help-center"

Done
----
Close the panel. The menu-bar bell stays running, and the app starts at login.
Open Help Center Monitor later from Spotlight to enable or disable monitoring.

If any row remains red, use the button beside it or contact the release owner.
